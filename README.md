# 🎾 Падел турніри

Веб-додаток для дружніх падел-турнірів у форматах **Мексикано** та **Американо**.
Mobile-first: розрахований на телефон просто на корті.

## Що вміє

- Створення турнірів: назва, формат, кількість кортів, гра до N поінтів (звичайний рахунок, не 15-30-40)
- База гравців — імена запамʼятовуються й доступні для наступних турнірів
- Необмежена кількість раундів: турнір триває, доки ви створюєте нові раунди
- Автоматичне жеребкування:
  - **Мексикано** — пари за поточним рейтингом (1+4 проти 2+3, лідери на 1-му корті)
  - **Американо** — партнери постійно змінюються, повтори пар і суперників мінімізуються
- Рівномірна ротація відпочинку, якщо гравців більше, ніж місць на кортах
- Підрахунок і по мʼячах (набрані поінти), і по виграних іграх
- Автозаповнення рахунку суперника до N
- Перемішати жереб, видалити раунд, додати гравця посеред турніру

## Стек

Node.js + Express + PostgreSQL, фронтенд — vanilla JS без збірки.

## Локальний запуск

```bash
npm install
export DATABASE_URL="postgres://user:pass@localhost:5432/padel"
npm start          # http://localhost:3000
npm test           # тести алгоритмів жеребкування
```

## Деплой на Railway

1. New Project → Deploy from GitHub repo → цей репозиторій
2. Add service → Database → **PostgreSQL**
3. У сервісі додатку: Variables → Add variable reference → `DATABASE_URL` з Postgres
4. Settings → Networking → Generate Domain

Схема БД створюється автоматично під час першого старту.

## Змінні середовища

| Змінна         | Опис                                          |
| -------------- | --------------------------------------------- |
| `DATABASE_URL` | рядок підключення до PostgreSQL (обовʼязково)  |
| `PORT`         | порт (Railway задає автоматично)              |

## API

| Метод    | Шлях                                    | Опис                          |
| -------- | --------------------------------------- | ----------------------------- |
| `GET`    | `/api/players`                          | база гравців                  |
| `POST`   | `/api/players`                          | додати гравця                 |
| `GET`    | `/api/tournaments`                      | список турнірів               |
| `POST`   | `/api/tournaments`                      | створити турнір               |
| `GET`    | `/api/tournaments/:id`                  | повний стан + таблиця         |
| `POST`   | `/api/tournaments/:id/rounds`           | згенерувати наступний раунд   |
| `POST`   | `/api/tournaments/:id/rounds/reshuffle` | перемішати останній раунд     |
| `DELETE` | `/api/tournaments/:id/rounds/last`      | видалити останній раунд       |
| `PATCH`  | `/api/matches/:id`                      | внести рахунок                |
